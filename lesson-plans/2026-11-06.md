# Lesson Plan: 2026-11-06

## Goals

- Understand how the class runs: sessions, transcripts, and extraction prompts.
- Understand the knowledge capture workflow this team is building.
- Start work on your own extraction prompt.

## Before class

- Read [SAGE: Saving All Gathered Expertise](https://isocpp.org/files/papers/P4046R0.pdf).
- Read [How an Agent Harness Works](../tutorials/tutorial-agent-harnesses.md).

## Tools

These tools live in the [tools-public](https://github.com/cppalliance/tools-public) repository.

| Tool | What it does |
|---|---|
| [mentograph](https://github.com/cppalliance/tools-public/blob/master/agents/mentograph.md) | Story-walk interviewer that captures a subject at full fidelity through conversation. |
| [nash](https://github.com/cppalliance/tools-public/blob/master/agents/nash.md) | Game theory editor that maintains a structured game document. |
| [briefer](https://github.com/cppalliance/tools-public/blob/master/analysis/briefer.md) | Structural analysis of an organization or institution that produces a single integrated brief. |
| [coc-blocker](https://github.com/cppalliance/tools-public/blob/master/analysis/coc-blocker.md) | Evidence collector for violations of the ISO Code of Ethics and Conduct. |
| [diligence](https://github.com/cppalliance/tools-public/blob/master/analysis/diligence.md) | Evaluates a consulting, services, or engineering firm for a specific engagement. |
| [sigint-analyst](https://github.com/cppalliance/tools-public/blob/master/analysis/sigint-analyst.md) | Dual-hypothesis signals analysis that distinguishes genuine civilians from political operators. |
| [make-how-to](https://github.com/cppalliance/tools-public/blob/master/how-to/make-how-to.md) | Builds a how-to manual that teaches how a named person thinks and works, from their written record. |

## Schedule

Times are flexible. Try this layout, keep what works, and adjust what does not.

| Block | Length | What happens |
|---|---|---|
| Session 1 | 50 min | Instructor teaches, tells stories, or answers questions. The session is transcribed. |
| Break | 10 min | |
| Individual study | 60 min | Add the transcript to the repo, run your extraction prompt, and work on your own prompt. |
| Lunch | | |
| Session 2 | 50 min | Second teaching session, built on the questions from study time. |
| Break | 15 min | The instructor leaves. |
| Team breakout | 30 min | The group reviews the output and writes the questions for the next session, without the instructor. |

## Session 1 topics

- Vision for Runvil and the Knowledge Capture Corporation.
- How the class works: interviews, stories, and turning them into experiences and principles.
- Extracting technical design decisions from the instructor.
- Format of the classes and the prompt each person will build.

- Build and refine your extraction prompt in your own student folder.
