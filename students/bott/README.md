# Harry Bott

- [prompts/Class1-ExtractionPrompt.md](prompts/Class1-ExtractionPrompt.md) turns one transcript into two things. The first is teachable decision heuristics, each written as "When [situation], [action], because [reason]", tagged as stated, demonstrated, or inferred, and packaged as a unit an adaptive tutor can deliver. The second is a list of knowledge gaps, each paired with a story-eliciting question for the next interview. It uses only the transcript, and it never supplies a reason the speaker didn't give.
- [outputs/2026-11-06-class-1.md](outputs/2026-11-06-class-1.md) is that prompt run on the [2026-11-06 class transcript](../../transcripts/2026-11-06-class-1.md). It has 38 heuristics and 18 gaps. The biggest gap is that no one said what a good extraction looks like.
